# Baselane mods

Claude Code mods by Baselane: guards, panes, bands, commands, sounds, styles and more. A mod is a Claude Code plugin of function hooks that runs inside Claude Code. See the [Claude Code mods docs](https://code.claude.com/docs/en/plugins/mods/overview).

## Install

Install these mods from the Baselane mods gallery, where each one is checked and pinned to a reviewed commit:

    /plugin marketplace add baselane-sh/mods-catalog
    /plugin install <name>@baselane-mods

Browse them at https://mods.baselane.sh.

This repo also has a development marketplace, `baselane-mods-dev`, that tracks `main`. Use it only to try unreleased changes:

    /plugin marketplace add baselane-sh/mods
    /plugin install <name>@baselane-mods-dev

## Layout

- `engines/<engine>/`: the shared engine for a family of mods, its rules and its tests.
- `catalog/<name>.json`: which rules each mod uses.
- `plugins/`: generated by `node scripts/build.mjs`. Do not edit it by hand.
- `scripts/check.sh`: rebuilds, then validates, tests and type-checks every mod.

Each mod is released with a tag `<name>--v<version>`.
